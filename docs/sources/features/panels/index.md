# Panels

Panels are the building blocks of Grafana dashboards. Each panel type has its
own data requirements, display options, and interaction model.

- [Graph]({{< relref "graph.md" >}}) - plot one or more time series as lines,
  bars, or points.
- [Singlestat]({{< relref "singlestat.md" >}}) - reduce a single series to one
  value with optional thresholds and sparkline context.
- [Table]({{< relref "table_panel.md" >}}) - transform time series,
  annotations, JSON, or table data into rows and columns.
- [Heatmap]({{< relref "heatmap.md" >}}) - visualize value density over time
  with time and value buckets.
