# Panels

Panels are the building blocks of a Grafana dashboard. Each panel type turns query results into a
different visualization or dashboard control.

- [Graph]({{< relref "graph.md" >}}) - Plot one or more time series with rich axis, legend, and
  display options.
- [Singlestat]({{< relref "singlestat.md" >}}) - Show one reduced value from a time series.
- [Table]({{< relref "table_panel.md" >}}) - Transform time series, table, annotation, or raw JSON
  data into rows and columns.
- [Dashboard list]({{< relref "dashlist.md" >}}) - Show links to starred dashboards, search results,
  or dashboards with selected tags.
- [Heatmap]({{< relref "heatmap.md" >}}) - Show a time-based distribution by bucketing numeric
  values into colored cards.
