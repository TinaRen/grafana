# Panels

Panels display the data returned by dashboard queries. Each panel type has its
own editor tabs and display options for transforming query results into a
visualization.

- [Graph]({{< relref "graph.md" >}}) - plot one or more time series over time.
- [Table]({{< relref "table_panel.md" >}}) - transform time series, table,
  annotation, or JSON data into rows and columns.
- [Singlestat]({{< relref "singlestat.md" >}}) - reduce a single series to one
  summary value.
- [Dashboard list]({{< relref "dashlist.md" >}}) - show dynamic links to other
  dashboards.
- [Heatmap]({{< relref "heatmap.md" >}}) - show value distributions over time.
