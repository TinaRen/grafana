# Panels

Panels are the building blocks of Grafana dashboards. Each panel runs one or
more queries and displays the returned data with a visualization suited to the
data shape.

## Available panel guides

- [Graph]({{< relref "graph.md" >}}) - plot time series as lines, bars, or points.
- [Singlestat]({{< relref "singlestat.md" >}}) - reduce one series to a single summary value.
- [Table]({{< relref "table_panel.md" >}}) - display time series, table, annotation, or raw JSON data in rows and columns.
- [Dashboard list]({{< relref "dashlist.md" >}}) - show links to starred or searched dashboards.
- [Heatmap]({{< relref "heatmap.md" >}}) - visualize value distributions over time as buckets.
