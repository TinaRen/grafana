# Panels

Panels are the building blocks of a Grafana dashboard. Each panel runs one or
more queries, transforms the returned data into a visualization, and exposes
panel-specific editor tabs for display options.

## Available panel documentation

* [Graph]({{< relref "graph.md" >}}) - Time series graphs with axes, legends,
  thresholds, and alerting.
* [Table]({{< relref "table_panel.md" >}}) - Tabular views for time series,
  table, annotation, and raw JSON data.
* [Singlestat]({{< relref "singlestat.md" >}}) - Single-value summaries with
  thresholds and sparklines.
* [Dashboard list]({{< relref "dashlist.md" >}}) - Dynamic links to starred or
  searched dashboards.
* [Heatmap]({{< relref "heatmap.md" >}}) - Distribution density over time using
  time series data or Elasticsearch histogram buckets.
