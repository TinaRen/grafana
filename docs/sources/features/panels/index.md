# Panels

Panels display data on a dashboard. Each panel type has its own editor options
for transforming query results and controlling how the data is drawn.

## Available panels

* [Graph]({{< relref "graph.md" >}}) - Plot time series as lines, bars, or
  points with axes, legends, thresholds, and series overrides.
* [Table]({{< relref "table_panel.md" >}}) - Transform time series, table,
  annotation, or JSON data into rows and columns.
* [Singlestat]({{< relref "singlestat.md" >}}) - Reduce one series to a single
  value with optional thresholds, sparklines, and value mappings.
* [Heatmap]({{< relref "heatmap.md" >}}) - Show the density of values over time
  using time buckets, value buckets, and count-based card colors.
