# Panels

Panels are the visualization building blocks in Grafana dashboards. Each panel
combines a query editor for the selected data source with visualization-specific
display options.

- [Graph]({{< relref "features/panels/graph.md" >}}) - Plot one or more time
  series as lines, bars, points, or stacked graphs.
- [Singlestat]({{< relref "features/panels/singlestat.md" >}}) - Reduce a
  single series to one summary value.
- [Table]({{< relref "features/panels/table_panel.md" >}}) - Display time
  series, annotations, JSON documents, or table data in rows and columns.
- [Dashboard list]({{< relref "features/panels/dashlist.md" >}}) - Link to
  starred dashboards or dashboards returned by a search.
- [Heatmap]({{< relref "features/panels/heatmap.md" >}}) - Show value
  distributions over time using colored buckets.
